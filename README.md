# Star OS Free (SOSP)
## "Modifique, crie e seja você mesmo."

Bem-vindo ao **Star Open Source Project (SOSP)**. Este é o repositório oficial do **Star OS Free**, um sistema operacional independente, focado em soberania tecnológica, aprendizado e facilidade de uso. 

O Star OS Free foi desenhado para ser o **Linux 2.0 Kids**: um ambiente onde crianças e iniciantes podem entender como o hardware e o software funcionam, sem perder a potência de um sistema profissional.

### Filosofia SOSP
Acreditamos que a tecnologia deve ser transparente. Nosso objetivo é remover as barreiras entre o usuário e a máquina. Se você quer aprender a construir um kernel, instalar drivers ou gerenciar pacotes, você está no lugar certo.

### Arquitetura do Sistema
O SOSP é estruturado para modularidade:
- `/core`: O Kernel independente e gerenciamento de memória.
- `/apps`: Aplicativos nativos e utilitários.
- `/scripts`: O nosso **APM (Aura Package Manager)**, o instalador mágico que suporta `.deb`, `.rpm` e `.exe`.
- `/docs`: Guias para novos arquitetos e contribuintes.

### Como começar?
Se você é um novo Arquiteto ou apenas quer testar o Star OS Free, confira nosso [Guia de Primeiros Passos](docs/guia-iniciante.md).

### Quer contribuir?
O SOSP é feito por você. 
1. Faça um Fork deste repositório.
2. Crie uma branch para a sua funcionalidade.
3. Envie um Pull Request.
4. Junte-se ao nosso sonho de um SO 100% livre.
